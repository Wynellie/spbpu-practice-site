# Учёба в Политехе

Лабораторные работы № 1 и № 2. Попов, СПбПУ.

Для просмотра открыть `index.html` в браузере.

- `pages` — остальные страницы.
- `css/style.css` — стили сайта и логотип.
- `css/pic.css` — рисунок трактора.
- `images` — изображения.
- `SOURCES.md` — источники фотографий.
