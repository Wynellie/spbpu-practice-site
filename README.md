# Учёба в Политехе

Учебный сайт Попова. HTML и CSS, без JavaScript, библиотек и сборки.

Открыть `index.html` в браузере. Все изображения находятся в проекте.

## Структура

- `index.html` — главная.
- `pages/journal.html` — об учёбе в Политехе.
- `pages/labs.html` — список лабораторных и место для курсовой.
- `pages/tractor.html` — лабораторная № 2.
- `css/style.css` — оформление и CSS-логотип.
- `css/pic.css` — рисунок трактора.
- `images/` — фотографии и образец.
- `SOURCES.md` — источники, авторы фотографий и лицензии.

## Для разбора на паре

`header`, `nav`, `main` и `footer` задают части страницы. Общая таблица стилей подключается через `link`.

`display: flex` размещает блоки рядом. На телефоне медиазапрос располагает их друг под другом. В статье `float: right` позволяет тексту обтекать фотографию.

Логотип — зелёный квадрат 44 × 44 px. Два белых псевдоэлемента изображают раскрытую книгу. Это собственный знак сайта, не эмблема университета.

Трактор находится в блоке 200 × 200 px с `position: relative`. Детали имеют абсолютные координаты. Колёса получаются через `border-radius`, наклонные края — из границ псевдоэлементов. Для поля используется линейный повторяющийся градиент, для солнца — радиальный. Внутри каждого кольца цвет идёт от светлого к оранжевому.

## Текущий объём

По просьбе автора страницы сокращены. На странице «Об учёбе» оставлены более 300 слов, четыре фотографии и обтекание изображения текстом. На всём сайте восемь фотографий кампуса плюс образец трактора, текста больше 2500 знаков. Страницы лабораторных короткие.

Если требование «300 слов и 4 изображения» преподаватель применяет к каждой странице отдельно, короткие страницы потребуют дополнения перед сдачей.
