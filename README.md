# За городом — лабораторные № 1 и № 2

Учебный сайт Попова для курса «Вёрстка и прототипирование сайтов», СПбПУ.

Чистые HTML и CSS. JavaScript, фреймворков, сторонних библиотек, сборщика и внешних шрифтов нет. Можно распаковать архив и открыть `index.html` двойным щелчком. Интернет для просмотра не нужен.

## Структура

```text
index.html                 Главная, лабораторная № 1
pages/
  journal.html             Большая статья с изображениями внутри текста
  labs.html                Список лабораторных и место для будущей курсовой
  tractor.html             Лабораторная № 2, рисунок и исходный образец
css/
  style.css                Общие стили и CSS-логотип
  pic.css                  Только рисунок трактора, 200 × 200 px
images/                    10 фотографий и образец трактора
SOURCES.md                 Источники изображений
README.md                  Запуск и пояснения для защиты
.nojekyll                  Служебный файл GitHub Pages
```

## Что выполнено

- Сайт на свободную тему, блочная семантическая вёрстка без таблиц.
- Единые шапка, меню и подвал на всех четырёх страницах.
- На каждой странице больше 300 слов и как минимум 4 тега `img`.
- 10 разных фотографий на сайте, плюс исходный образец трактора. Текстов суммарно значительно больше 2500 знаков.
- Длинная статья с оглавлением, внутренними ссылками и обтеканием фотографии текстом.
- Собственный логотип размером 48 × 48 px, полностью на CSS.
- Страница для лабораторных и обозначенное место для будущей курсовой работы.
- Трактор выполнен только средствами CSS в отдельном файле `css/pic.css`.
- Рисунок остаётся размером 200 × 200 px на любом экране.
- Адаптивный макет для широких и узких экранов. Все локальные ссылки относительные.

## Что объяснять на паре

### 1. Логическая и физическая структура

Логическая структура — это разделы и переходы: главная → журнал или лабораторные → рисунок. Физическая — папки и файлы. `index.html` лежит в корне, остальные страницы в `pages`, фотографии в `images`, стили в `css`.

Из `index.html` путь к стилям — `css/style.css`. Из папки `pages` он выглядит как `../css/style.css`: две точки означают «подняться на один уровень».

### 2. Основные теги

`header` — шапка, `nav` — навигация, `main` — основное содержание, `section` — тематический раздел, `article` — самостоятельная статья, `aside` — дополнительная информация, `footer` — подвал. `figure` объединяет изображение с подписью `figcaption`. Заголовок страницы — `h1`, разделы — `h2`, подразделы — `h3`.

### 3. Подключение CSS и селекторы

`link rel="stylesheet"` подключает внешний файл стилей. Правило `p` относится ко всем абзацам, `.card` — к элементам с классом `card`, `.card p` — только к абзацам внутри карточки. `:hover` описывает наведение, `:focus-visible` — видимый фокус при навигации клавиатурой.

### 4. Размеры и расположение

Контейнер занимает 90% ширины окна, но не больше 1180 px, и центрируется с помощью `margin: 0 auto`. `padding` — внутренний отступ, `margin` — внешний, `border` — граница. `box-sizing: border-box` включает внутренние отступы и границы в заданную ширину.

`display: flex` ставит дочерние блоки рядом. `gap` задаёт промежуток между ними. На узком экране `flex-direction: column` располагает те же блоки вертикально. Высота текстовых разделов не фиксирована, поэтому они растут вместе с текстом.

В статье `float: right` позволяет тексту обтекать изображение справа. `display: flow-root` у раздела удерживает плавающую картинку внутри его границ. На телефоне `float` отключается.

### 5. Адаптивность

Тег `meta name="viewport"` сообщает браузеру, что ширина страницы должна соответствовать ширине устройства. В `@media (max-width: 600px)` меняются размеры заголовков, колонки и расположение меню. Шапка остаётся обычным видимым меню, без JavaScript.

### 6. CSS-логотип

`.logo` — круг 48 × 48 px с обрезанием выступающих частей через `overflow: hidden`. Солнце — `::before`, один холм — `::after`, второй — вложенный `span`. `border-radius` закругляет фигуры, `position: absolute` позволяет расположить их внутри логотипа.

Псевдоэлемент — дополнительная декоративная часть элемента, которую CSS создаёт без отдельного тега в HTML. Для него указывается `content: ""`.

### 7. Трактор

Открой `pages/tractor.html` и `css/pic.css` рядом. Внутри `.picture` перечислены детали с понятными названиями: `sun`, `cloud`, `roof`, `seat`, `wheel`, `field`.

- `position: relative` у родителя создаёт точку отсчёта для вложенных абсолютных элементов.
- `left`, `top`, `width`, `height` задают координаты и размеры детали.
- Круг получается из квадрата с `border-radius: 50%`.
- Толстая коричневая граница круга изображает шину.
- Треугольник получается из цветной и прозрачной границ псевдоэлемента.
- `linear-gradient` создаёт переход цвета, `repeating-linear-gradient` повторяет полосы поля.
- Несколько `box-shadow` без размытия создают кольца солнца.
- Детали, стоящие позже в HTML, перекрывают предыдущие. Поэтому колёса идут после корпуса.
- `overflow: hidden` обрезает облака и солнце по границам рисунка.

Градиенты, Flexbox, обтекание и псевдоэлементы используются в небольшом количестве. Если спросят, почему нет анимации: в задании требуется статичный рисунок, движение не указано.

### 8. Доступность и изображения

`alt` описывает фотографию, если её нельзя увидеть. У дублирующих ссылку картинок в карточках `alt` пустой: название ссылки уже находится рядом. CSS-рисунок имеет `role="img"` и текстовое описание `aria-label`. В начале каждой страницы есть ссылка для перехода к содержимому с клавиатуры.

`object-fit: cover` заполняет область фотографией без искажения её пропорций. `loading="lazy"` разрешает браузеру загружать нижние изображения по мере прокрутки. Системные Arial и Georgia работают без загрузки шрифтов.
